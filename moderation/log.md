# Moderation log

The human-readable log of moderation actions. Git history is authoritative:
every action is a commit whose message starts with `Merge:`, `Reject:`,
`Neutralize:`, `Edit:`, `Veto:`, `Roster:` or `Charter:` and gives a reason.
This file summarizes them for readers; if it ever disagrees with the commits,
the commits win.
